📚 Teoria w pigułce

Każdy program w C++ ma określoną strukturę. Zobaczmy to na przykładzie:

#include <iostream>      // 1. Import biblioteki
using namespace std;     // 2. Przestrzeń nazw

int main() {             // 3. Główna funkcja
    int wiek;            // 4. Deklaracja zmiennej
    
    cout << "Ile masz lat? "; // 5. Wypisywanie
    cin >> wiek;              // 6. Wczytywanie
    
    cout << "Masz " << wiek << " lat!" << endl;
    
    return 0;            // 7. Zakończenie programu
}

Co oznaczają te instrukcje?

  • #include <iostream>: To prośba do komputera: "Daj mi narzędzia do obsługi wejścia i wyjścia (Input/Output)". Bez tego cin i cout nie zadziałają.
  • using namespace std;: Standardowe komendy C++ znajdują się w "paczce" zwanej std. Dzięki tej linijce nie musisz pisać std::cout, wystarczy samo cout.
  • int main() { ... }: To serce programu. Komputer zawsze zaczyna czytanie Twojego kodu od tego miejsca.
  • cout <<: (Console Out) Służy do wypisywania tekstu na ekran. Strzałki << pokazują kierunek danych (z kodu do ekranu).
  • cin >>: (Console In) Służy do pobierania danych z klawiatury. Strzałki >> pokazują, że dane wędrują z klawiatury do Twojej zmiennej.
  • endl: To skrót od "end line" – przeskakuje do nowej linii.

Kod ASCII i Typ char

🎯 Kluczowa Koncepcja Maturalna:
W języku C++ typ char nie jest wyłącznie "literą" – to **8-bitowa liczba całkowita bez znaku lub ze znakiem** (zakres od 0 do 127 w standardowym ASCII). Komputer nie przechowuje w pamięci znaków 'A', 'a' czy '0', lecz odpowiadające im kody liczbowe. Dzięki temu na znakach w C++ możemy wykonywać pełną arytmetykę (dodawanie, odejmowanie, modulo).

1. Tablica ASCII i Kluczowe Przedziały

Na maturze z informatyki nie musisz pamiętać całej tablicy ASCII na pamięć, ale musisz znać trzy najważniejsze przedziały oraz relacje między nimi:

Wielkie Litery ('A' - 'Z')
65 do 90
'A' = 65, 'B' = 66, ..., 'Z' = 90
Małe Litery ('a' - 'z')
97 do 122
'a' = 97, 'b' = 98, ..., 'z' = 122
Cyfry Znakowe ('0' - '9')
48 do 57
'0' = 48, '1' = 49, ..., '9' = 57
💡 Zapamiętaj Różnicę: Różnica wartości między małą a wielką literą w ASCII (np. 'a' - 'A') wynosi zawsze 32. Ponadto ciągi liter i cyfr są ułożone w tabeli **spójnie (kolejno)**.

🔬 Symulator 1: Podgląd Zmiennej char w Pamięci RAM

Wpisz pojedynczy znak, aby zobaczyć jego reprezentację w kodzie ASCII, systemie binarnym i szesnastkowym.

➔
DEC (int): 65
BIN (8-bit): 01000001
HEX (16): 0x41

Znak 'A' zajmuje dokładnie 1 bajt w pamięci operacyjnej.

2. Cztery Kluczowe Operacje Maturalne

Na egzaminie maturalnym operacje na kodach ASCII wykorzystuje się do czyszczenia danych, analizy napisów oraz algorytmów szyfrujących.

2.1. Zamiana cyfry znakowej na wartość liczbową

Jeśli czytasz plik tekstowy znak po znaku i napotkasz cyfrę '7', jej kodem ASCII jest 55. Aby przekształcić ją w prawdziwą liczbę 7, odejmujesz kod zera '0' (wartość 48):

char c = '7';
int cyfra = c - '0'; // 55 - 48 = 7

2.2. Zmiana wielkości liter (upper / lower case)

Zamiana małej litery na dużą wymaga odjęcia wartości 32 (lub odjęcia 'a' i dodania 'A'):

char mala = 'g';
char duza = mala - 32; // 'g' (103) - 32 = 'G' (71)
char duza_alt = mala - 'a' + 'A'; // Bardziej czytelne na maturze!

2.3. Numerowanie liter w alfabecie (Indeksowanie 0–25)

Często musimy zliczać wystąpienia liter w tablicy liczników (histogram). Służy do tego przeniesienie znaku na zakres 0–25:

char litera = 'C';
int idx = litera - 'A'; // 'C' (67) - 'A' (65) = 2
liczniki[idx]++; // Zwiększa licznik dla litery 'C'

2.4. Szyfr Cezara i Przesunięcie Cykliczne (Modulo)

Przesunięcie znaku w alfabecie o $K$ pozycji z zawijaniem na końcu (po 'Z' wracamy do 'A') wymaga użycia operatora modulo `% 26`:

🔐 Symulator 2: Szyfr Cezara na Kodach ASCII

Zobacz, jak matematyka na kodach ASCII pozwala przesuwać litery w alfabecie.

➔
Wzór: (c - 'A' + K) % 26 + 'A'
Wynik: A

Dla 'X' (88) + 3 przeskakujemy koniec alfabetu i wracamy do 'A' (65).

3. Kompletny Kod C++ do Zadań Maturalnych

Poniższy program prezentuje wykorzystanie funkcji nagłówka <cctype> (np. isalpha, isdigit, toupper) oraz czystych operacji arytmetycznych na ASCII:

#include <iostream>
#include <string>
#include <cctype> // Przydatne funkcje: isdigit(), isalpha(), toupper(), tolower()

using namespace std;

// Funkcja szyfrująca pojedynczą wielką literę Szyfrem Cezara
char szyfrujZnak(char c, int k) {
    if (c >= 'A' && c <= 'Z') {
        return (c - 'A' + k) % 26 + 'A';
    }
    return c; // Jeśli to nie litera, zwracamy bez zmian
}

int main() {
    string tekst = "MaturA2026";
    int sumaCyfr = 0;

    cout << "Oryginalny tekst: " << tekst << endl;

    // 1. Analiza znak po znaku
    for (char &c : tekst) {
        // Sprawdzanie czy znak jest cyfrą
        if (isdigit(c)) {
            sumaCyfr += (c - '0'); // Zamiana char na int
        }
        // Zamiana małych liter na duże
        else if (c >= 'a' && c <= 'z') {
            c = c - 'a' + 'A';
        }
    }

    cout << "Tekst po zamianie na wielkie litery: " << tekst << endl;
    cout << "Suma cyfr zawartych w tekscie: " << sumaCyfr << endl;

    // 2. Szyfrowanie tekstu o klucz k = 3
    string zaszyfrowany = "";
    for (char c : tekst) {
        zaszyfrowany += szyfrujZnak(c, 3);
    }

    cout << "Zaszyfrowany tekst (K=3): " << zaszyfrowany << endl;

    return 0;
}

📚 Składnia instrukcji if

Instrukcja if (jeśli) sprawdza, czy warunek w nawiasie jest prawdziwy. Jeśli tak – wykonuje kod pod spodem. Jeśli nie – może wykonać kod z sekcji else (w przeciwnym razie).

int wiek;
cout << "Ile masz lat? ";
cin >> wiek;

if (wiek >= 18) {
    cout << "Jestes pelnoletni!";
} else {
    cout << "Nie jestes pelnoletni.";
}

🔍 Operatory porównania

Aby stworzyć warunek, używamy specjalnych symboli:

Symbol Znaczenie Przykład
== Jest równe (uwaga: dwa znaki równości!) if (a == 10)
!= Jest różne od if (a != 0)
> , < Większe , Mniejsze if (a > 5)
>= , <= Większe bądź równe , Mniejsze bądź równe if (a <= 100)
⚠️ Częsty błąd:
Początkujący często piszą if (a = 5) zamiast if (a == 5). Jeden znak równości to przypisanie wartości do zmiennej, a dwa znaki to porównanie.

Jeśli pierwsza instrukcja if nie zostanie spełniona, możesz sprawdzić kolejną za pomocą else if. Program sprawdza je po kolei, aż znajdzie pierwszą prawdziwą.

🔌 Instrukcja switch

Gdy sprawdzasz jedną zmienną pod kątem konkretnych wartości (np. numer dnia tygodnia lub wybór z menu), instrukcja switch jest znacznie czytelniejsza niż wiele if-ów.

int wybor;
cout << "Wybierz napoj: 1-Kawa, 2-Herbata: ";
cin >> wybor;

switch (wybor) {
    case 1:
        cout << "Parze kawe...";
        break; 
    case 2:
        cout << "Parze herbate...";
        break;
    default:
        cout << "Nie ma takiej opcji!";
}
⚠️ Pamiętaj o break!
Słowo break mówi komputerowi: "Skończyłem, wyjdź ze switcha". Jeśli o nim zapomnisz, program wykona kod z następnego case, nawet jeśli numer się nie zgadza!

    cout << "Wybierz: 1-suma, 2-roznica, 3-iloczyn: ";
    cin >> operacja;

    switch (operacja) {
        case 1: cout << "Wynik: " << a + b; break;
        case 2: cout << "Wynik: " << a - b; break;
        case 3: cout << "Wynik: " << a * b; break;
        default: cout << "Bledny wybor!";
    }

    return 0;
}

Pojęcie pętli i pętla for

🎯 Cel lekcji:
Zrozumiesz, jak zmusić komputer do powtarzania czynności określoną liczbę razy. Poznasz budowę pętli for, która jest fundamentem niemal każdego algorytmu maturalnego.

📚 Po co nam pętle?

Wyobraź sobie, że musisz wypisać liczby od 1 do 100. Pisanie tego ręcznie byłoby męczące i łatwo o błąd. Pętla pozwala zapisać to tak:

for (int i = 1; i <= 100; i++) {
    cout << i << " ";
}

🏗️ Budowa pętli for

Pętla for składa się z trzech części oddzielonych średnikami:

  1. Inicjalizacja (int i = 0): Tu tworzymy "licznik" i mówimy, od ilu zaczynamy.
  2. Warunek (i < 10): Pętla działa tak długo, jak ten warunek jest prawdziwy.
  3. Krok (i++): Co dzieje się z licznikiem po każdym powtórzeniu (i++ oznacza zwiększenie o 1).

🔍 Przykłady zastosowań

// Wypisanie tekstu 5 razy
for (int i = 0; i < 5; i++) {
    cout << "Nie bede rozmawial na lekcji" << endl;
}

// Liczenie od 10 w dół (odliczanie)
for (int i = 10; i >= 1; i--) {
    cout << i << "... ";
}
💡 Zapamiętaj:
Zmienna i (skrót od index lub iterator) jest widoczna tylko wewnątrz pętli. Po jej zakończeniu "licznik" znika z pamięci.

🧩 Bonus: Pętle zagnieżdżone (Klucz do Macierzy)

💡 Analogia zegara:
Pętla zewnętrzna to godziny, a wewnętrzna to minuty. Minuty muszą zrobić pełne 60 kroków, żeby godzina zmieniła się o 1.

W programowaniu pętle zagnieżdżone służą do obsługi wszystkiego, co ma dwa wymiary: tabel, obrazków (pikseli) czy współrzędnych X i Y.

// Przykład: Tabliczka mnożenia 3x3
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        cout << i * j << "\t"; // \t to tabulator (ładny odstęp)
    }
    cout << endl; // Nowy wiersz
}

Pętle warunkowe: while oraz do-while

🎯 Cel lekcji:
Nauczysz się używać pętli, które działają dopóki pewien warunek jest spełniony. Dowiesz się, kiedy lepiej użyć while, a kiedy do-while.

📚 Pętla while

Pętla while (dopóki) sprawdza warunek zanim wykona kod. Jeśli warunek od początku jest fałszywy, kod wewnątrz pętli nie wykona się ani razu.

int i = 1;
while (i <= 5) {
    cout << "Numer: " << i << endl;
    i++; // Bardzo ważne: musimy zmieniać licznik, żeby pętla się skończyła!
}

📚 Pętla do-while

Różnica polega na tym, że do-while najpierw wykonuje kod, a dopiero potem sprawdza warunek. Gwarantuje to, że pętla wykona się przynajmniej jeden raz.

int liczba;
do {
    cout << "Podaj liczbe dodatnia: ";
    cin >> liczba;
} while (liczba <= 0); 

cout << "Dziekuje, Twoja liczba to: " << liczba;

Złożoność obliczeniowa i pamięciowa

🎯 Cel lekcji:
Dowiesz się, dlaczego jeden program działa w ułamek sekundy, a inny zawiesza komputer.

🤔 O co w ogóle chodzi? (Analogia z życia)

Wyobraź sobie, że szukasz słowa w słowniku:

  • Sposób 1 (Fatalny): Kartkujesz słownik strona po stronie od samego początku do końca, aż znajdziesz szukane słowo. Jeśli słownik ma 100 stron – zajmie to chwilę. Jeśli ma 10 000 stron – spędzisz nad tym całe popołudnie.
  • Sposób 2 (Sprytny): Otwierasz słownik na środku. Jeśli szukane słowo jest w alfabecie dalej, wyrzucasz lewą połowę i szukasz tylko w prawej. W każdym kroku odrzucasz połowę książki!

Złożoność obliczeniowa to miara tego, jak bardzo Twój program zwalnia, gdy rośnie liczba danych wejściowych (czyli nasz "rozmiar słownika").

📊 Najważniejsze "tempa" programów

W informatyce prędkość algorytmów zapisujemy za pomocą tzw. notacji Big O (literka $O$ oznacza "rzędu wielkości"). Oto najważniejsze z nich:

  • O(1) – Tempo stałe (Błyskawiczne):
    Niezależnie od tego, czy w bazie masz 10, czy 100 000 000 elementów, komputer robi to w tym samym czasie.
    Przykład: Sprawdzenie elementu tablicy po indeksie, np. tab[5]. To jak wyciągnięcie telefonu z kieszeni – bez względu na to, ile masz ubrań w szafie, ruch jest jeden.

  • O(n) – Tempo liniowe (Uczciwe):
    Jeśli danych ($n$) będzie 10 razy więcej, to program będzie szukał 10 razy dłużej. Wykres to prosta linia w górę.
    Przykład: Zwykła pętla od 0 do $n$, która sprawdza każdy element po kolei.

  • O(n²) – Tempo kwadratowe (Niebezpieczne!):
    Gdy dane wzrosną 10 razy, program zwolni aż 100 razy ($10 \times 10$). Często pojawia się, gdy mamy pętlę w pętli (tzw. pętle zagnieżdżone).
    Przykład: Porównywanie każdego elementu tablicy z każdym innym. Przy małych danych (np. $n = 100$) zadziała OK, ale przy $n = 100 000$ komputer będzie liczył wynik do następnej matury.

Tablice statyczne – fundament zbiorów danych

🎯 Cel lekcji:
Nauczysz się przechowywać wiele wartości tego samego typu w jednej zmiennej. Dowiesz się, jak deklarować tablice i jak bezpiecznie z nich korzystać, nawet gdy ich rozmiar podaje użytkownik.

🏗️ Deklaracja i indeksowanie

Podstawowy sposób deklaracji tablicy to podanie jej rozmiaru "na sztywno":

int liczby[100]; // Rezerwujemy miejsce na dokładnie 100 liczb

🤔 Czy można zrobić int tab[n]?

Często na lekcjach spotkasz się z takim zapisem:

int n;
cin >> n;
int tab[n]; // Rozmiar zależy od użytkownika

Tak, to zadziała! Większość kompilatorów (w tym te maturalne) na to pozwala. Jest to bardzo wygodne, ale musisz pamiętać o dwóch ryzykach:

  • Ryzyko 1: Przepełnienie stosu (Stack Overflow). Zwykłe tablice lądują w bardzo małym fragmencie pamięci. Jeśli n będzie bardzo duże (np. milion), program nagle się wyłączy.
  • Ryzyko 2: Brak elastyczności. Raz stworzona tablica tab[n] nie może już urosnąć. Jeśli użytkownik nagle zechce dodać n+1 elementów, program "wyjdzie poza zakres" i może działać błędnie.

Wniosek: Na maturze przy mniejszych zadaniach możesz tak robić, ale przy pracy z ogromnymi plikami tekstowymi bezpieczniejszy będzie vector (Lekcja 3.2).

🔄 Przetwarzanie tablicy pętlą

Gdy mamy już tablicę o rozmiarze n, najwygodniej obsłużyć ją pętlą for:

int n;
cout << "Ile liczb podasz? ";
cin >> n;

int t[n]; // Deklarujemy tablicę o rozmiarze n

for (int i = 0; i < n; i++) {
    cin >> t[i]; // Wczytujemy n elementów
}

cout << "Twoja tablica w odwrotnej kolejnosci: ";
for (int i = n - 1; i >= 0; i--) {
    cout << t[i] << " ";
}
⚠️ Zasada n-1:
Niezależnie od tego, czy zadeklarujesz int t[10] czy int t[n], ostatni dostępny indeks to zawsze rozmiar - 1.

🆚 Tablica vs Wektor – Kluczowe różnice

  • v.pop_back() – Usuwa ostatni element.
  • v.clear() – Czyści cały wektor do zera.

Algorytm: Znajdowanie Min i Max

🎯 Cel lekcji:
Nauczysz się, jak przeszukać cały zbiór danych, aby wyłonić wartość najmniejszą lub największą. Poznasz metodę "Króla Góry", która jest fundamentem zadań maturalnych.

👑 Metoda "Króla Góry"

Wyobraź sobie, że masz worek liczb. Jak znaleźć największą? Bierzesz pierwszą z brzegu i ogłaszasz ją tymczasowym liderem (Max). Potem wyciągasz kolejne liczby – jeśli któraś jest większa od lidera, to ona zajmuje jego miejsce. Na końcu ten, kto przetrwał, jest prawdziwym zwycięzcą.

💻 Implementacja: Tablica vs Wektor

Zauważ, że algorytm wygląda niemal identycznie. Główną różnicą jest sposób sprawdzania rozmiaru (stała N vs metoda .size()).

Wariant: Tablica

int tab[5] = {12, 7, 19, 3, 11};
int max = tab[0]; // Lider

for (int i = 1; i < 5; i++) {
    if (tab[i] > max) {
        max = tab[i];
    }
}

Wariant: Wektor

vector<int> v = {12, 7, 19, 3, 11};
int max = v[0]; // Lider

for (int i = 1; i < v.size(); i++) {
    if (v[i] > max) {
        max = v[i];
    }
}
⚠️ Najczęstszy błąd: Inicjalizacja zerem
Jeśli szukasz MAX w liczbach ujemnych (np. -5, -10, -3) i ustawisz int max = 0;, program wypisze 0, mimo że zero w ogóle nie wystąpiło w danych!
Złota zasada: Zawsze ustawiaj max = pierwszy_element;.

🔍 Znajdowanie pozycji (indeksu)

Często na maturze pytanie nie brzmi "ile wynosi max", ale "który z kolei to był element". Wtedy musimy zapamiętać też indeks.

int maxVal = v[0];
int maxIdx = 0; // Pamiętamy pozycję lidera

for (int i = 1; i < v.size(); i++) {
    if (v[i] > maxVal) {
        maxVal = v[i];
        maxIdx = i; // Aktualizujemy pozycję
    }
}
cout << "Najwieksza wartosc " << maxVal << " jest na indeksie " << maxIdx;

📉 Budowa macierzy

Tablica jednowymiarowa to był "pociąg". Tablica dwuwymiarowa to szachownica lub arkusz Excel. Aby dostać się do konkretnego pola, musisz podać dwa adresy: tab[wiersz][kolumna].

🏗️ Deklaracja i dostęp

Przy deklaracji podajemy najpierw liczbę wierszy, a potem kolumn. Pamiętaj: indeksujemy od 0!

// Macierz o 3 wierszach i 4 kolumnach (łącznie 12 miejsc)

// Przypisanie wartości do lewego górnego rogu (wiersz 0, kolumna 0):

// Przypisanie wartości do prawego dolnego rogu (ostatni wiersz, ostatnia kolumna):
macierz[2][3] = 10;

🔄 Przetwarzanie: Pętla w pętli

To jest kluczowy moment. Zewnętrzna pętla (zwykle i) odpowiada za wiersze, a wewnętrzna (zwykle j) "przebiega" przez wszystkie kolumny w danym wierszu.

int W = 10, K = 10;
int obraz[10][10];

// Wypełnianie macierzy zerami (czyszczenie arkusza)
for (int i = 0; i < W; i++) {
    for (int j = 0; j < K; j++) {
        obraz[i][j] = 0; // Ustawiamy 0 w każdym polu
    }
}
🎨 Przykład maturalny: Negatyw obrazu
Jeśli każde pole macierzy to jasność piksela (0-255), to aby zrobić negatyw, musisz odjąć aktualną wartość od 255: obraz[i][j] = 255 - obraz[i][j];

🎯 Cel lekcji:

🔍 Na czym polega przeszukiwanie liniowe?

To najprostsza metoda: idziesz od początku do końca (element po elemencie) i sprawdzasz, czy to jest to, czego szukasz. Jeśli znajdziesz – przerywasz lub liczysz wystąpienia.

💻 Kod: Czy liczba istnieje w zbiorze?

Używamy zmiennej typu bool (flagi), która powie nam "TAK" lub "NIE" na koniec pętli.

vector<int> dane = {14, 5, 8, 22, 10, 3};
int szukana;
cout << "Czego szukasz? ";
cin >> szukana;

bool znaleziono = false;

for (int i = 0; i < dane.size(); i++) {
    if (dane[i] == szukana) {
        znaleziono = true;
        break; // Znaleźliśmy! Nie ma sensu sprawdzać dalej.
    }
}

if (znaleziono) cout << "Liczba jest w zbiorze!";
else cout << "Brak takiej liczby.";
⚡ Dlaczego używamy break?
Wyobraź sobie, że szukasz nazwiska w bazie 1 000 000 osób. Jeśli znajdziesz je na 5. pozycji, nie chcesz, żeby komputer sprawdzał pozostałe 999 995 rekordów. break natychmiast wychodzi z pętli.

📊 Złożoność algorytmu (Wstęp)

W informatyce oceniamy, jak szybki jest algorytm. Przeszukiwanie liniowe ma złożoność O(n). Co to znaczy? Jeśli masz 10 razy więcej danych, komputer będzie potrzebował 10 razy więcej czasu.

🤔 Problem: Kiedy zwykłe zmienne to za mało

Wyobraź sobie, że piszesz program do obsługi szkoły i musisz zapisać dane ucznia: imię, wiek i średnią ocen. Bez struktur musiałbyś tworzyć osobne zmienne:

📦 Jak zdefiniować i użyć struktury?

Strukturę tworzymy zazwyczaj poza funkcją main, opisując z jakich "pól" się składa:

#include <iostream>

    double srednia;

    u1.imie = "Kuba";
    u1.wiek = 18;
    u1.srednia = 4.2;

    // 3. Odczytujemy dane za pomocą kropki (.)
    cout << "Uczeń: " << u1.imie << ", wiek: " << u1.wiek << "\n";

}

Zasięg zmiennych (Lokalne vs Globalne)

🎯 Cel lekcji:
Zrozumiesz, gdzie "żyją" Twoje zmienne i dlaczego próba użycia zmiennej z funkcji wewnątrz main() często kończy się błędem kompilacji.

🏠 Zmienne Lokalne (Mieszkańcy pokoi)

Zmienna stworzona wewnątrz klamerek { } funkcji jest lokalna. Istnieje tylko wtedy, gdy funkcja pracuje. Gdy funkcja kończy działanie, zmienna jest usuwana z pamięci.

void funkcja() {
    int x = 10; // Zmienna lokalna
    cout << x;
}

int main() {
    funkcja();
    cout << x; // BŁĄD! main nie wie, co to jest x.
    return 0;
}

🌍 Zmienne Globalne (Ulica)

Jeśli stworzysz zmienną poza wszystkimi funkcjami (na samej górze pliku), będzie ona globalna. Każda funkcja w programie może ją czytać i zmieniać.

int licznik = 0; // Zmienna GLOBALNA

void zwieksz() {
    licznik++; // Ma dostęp do zmiennej
}

int main() {
    zwieksz();
    cout << licznik; // Wypisze 1
    return 0;
}
⚠️ Ważna uwaga:
Choć zmienne globalne wydają się wygodne, zawodowi programiści ich unikają. Dlaczego? Bo gdy program ma 1000 linii, trudno upilnować, która funkcja i kiedy zmieniła wartość globalną. To najczęstsze źródło błędów!

🛡️ Konflikt nazw

Co się stanie, jeśli masz zmienną globalną int x = 5; i lokalną o tej samej nazwie? Funkcja zawsze wybierze tę, która jest "bliżej" (lokalną). Nazywamy to przesłanianiem zmiennych.

Przekazywanie przez referencję (&)

🎯 Cel lekcji:
Dowiesz się, jak pozwolić funkcji modyfikować zmienne, które znajdują się w main(). Zrozumiesz różnicę między pracą na "kopii" a pracą na "oryginale".

1. Problem: Dlaczego funkcja "nie zmienia" moich danych?

Spójrz na poniższy kod. Chcemy, aby funkcja zwieksz dodała 10 do naszej zmiennej. Przeczytaj go i zastanów się, co wypisze komputer.

void zwieksz(int n) {
    n = n + 10; 
}

int main() {
    int liczba = 5;
    zwieksz(liczba);
    cout << "Wynik: " << liczba; // Wypisze 5, a nie 15!
    return 0;
}

Co się stało? C++ domyślnie jest bardzo ostrożny. Kiedy przekazujesz liczba do funkcji, C++ robi jej kserokopię. Funkcja zmienia tylko tę kopię, a gdy kończy pracę, wyrzuca ją do kosza. Oryginał w main() pozostaje nietknięty.

2. Rozwiązanie: Magiczny znak &

Aby funkcja pracowała na oryginale, musimy jej to wyraźnie powiedzieć. Służy do tego symbol ampersand (&) postawiony przy typie danych w nagłówku funkcji.

// Dodajemy & przed nazwą parametru (int &n)
void zwiekszNaprawde(int &n) {
    n = n + 10; // Teraz n to "ksywka" dla naszej zmiennej z main
}

int main() {
    int liczba = 5;
    zwiekszNaprawde(liczba);
    cout << "Wynik: " << liczba; // TERAZ WYPISZE 15!
    return 0;
}

2. Jak Czytać Plik, gdy NIE WIEMY, ile Jest Danych?

Na maturze rzadko podana jest dokładna liczba wierszy w pliku. Standard C++ udostępnia niezwykle prostą konstrukcję: użycie samych operatorów odczytu w warunku pętli while.

Pętla wykonuje się tak długo, jak długo strumień sukcesywnie pobiera kolejne porcje danych. Gdy plik się skończy (lub napotka błąd), pętla automatycznie się zatrzymuje.

}

Sposób 2: Całymi liniami (getline)

}

Sortowanie Bąbelkowe (Bubble Sort)

🎯 Cel lekcji:
Nauczysz się, jak uporządkować liczby w tablicy od najmniejszej do największej. Zrozumiesz mechanizm "wypływania" elementów i zobaczysz, jak pętle zagnieżdżone współpracują ze sobą w praktyce.

🔵 Dlaczego "Bąbelkowe"?

Wyobraź sobie bąbelki powietrza w szklance wody – te największe najszybciej lecą do góry. W tym algorytmie największa liczba w każdym przejściu pętli "wędruje" na sam koniec tablicy. Po każdym pełnym przejściu, kolejna największa wartość osiada na swoim docelowym miejscu.

🎮 Symulator Bąbelka (Krok po kroku)

Kliknij "Wylosuj tablicę", aby zacząć.

💻 Analiza Twojego kodu

Pętla zewnętrzna (i) pilnuje liczby przejść, a pętla wewnętrzna (j) "przepycha" największy element na koniec.

void Sortuj(int a[], int n) {
    for(int i = 0; i < n - 1; i++) {
        for(int j = 0; j < n - 1 - i; j++) {
            // SYMULATOR pokazuje moment wewnątrz tej pętli:
            if(a[j] > a[j+1]) {
                swap(a[j], a[j+1]); // Tu dzieje się magia!
            }
        }
    }
}

🔍 Jak to czytać?

  • Pętla i: Odpowiada za to, ile razy musimy "przepchnąć" bąbelki. Jeśli mamy 5 liczb, wystarczą 4 przejścia, by wszystko było na miejscu.
  • Pętla j: To nasz skaner. Porównuje a[0] z a[1], potem a[1] z a[2] itd.
  • Zapis n - 1 - i: To klucz do optymalizacji! Skoro po pierwszym przejściu największa liczba jest już na końcu (indeks n-1), to w kolejnym kroku nie musimy już tam zaglądać. Oszczędzamy czas procesora.

🐢 Symulacja "Krok po kroku"

Załóżmy, że mamy tablicę: [5, 1, 4, 2]

Etap 1 (i = 0):
[5, 1, 4, 2] -> (5 > 1?) TAK -> [1, 5, 4, 2]
[1, 5, 4, 2] -> (5 > 4?) TAK -> [1, 4, 5, 2]
[1, 4, 5, 2] -> (5 > 2?) TAK -> [1, 4, 2, 5] (5 jest bezpieczna!)

Etap 2 (i = 1):
[1, 4, 2, 5] -> (1 > 4?) NIE -> [1, 4, 2, 5]
[1, 4, 2, 5] -> (4 > 2?) TAK -> [1, 2, 4, 5] (4 jest bezpieczna!)

Etap 3 (i = 2):
[1, 2, 4, 5] -> (1 > 2?) NIE -> [1, 2, 4, 5] (Gotowe!)

💡 Algorytmiczne "bebechy": Zamiana bez funkcji swap

W Twoim kodzie używamy swap(a[j], a[j+1]). Na maturze lub egzaminie pisemnym często musisz zapisać to "na piechotę". Wyobraź sobie, że masz dwie szklanki soku: A (pomarańczowy) i B (jabłkowy). Nie możesz przelać A do B, bo smaki się zmieszają!

Potrzebujesz trzeciej, pustej szklanki (temp):

int temp = a[j]; // 1. Przelej sok ze szklanki A do temp
a[j] = a[j+1]; // 2. Szklanka A jest pusta, przelej do niej B
a[j+1] = temp; // 3. Do szklanki B przelej sok z temp

Dlaczego to ważne? Bez zmiennej temp, linijka a[j] = a[j+1] bezpowrotnie skasowałaby wartość, która była w a[j].

Sortowanie przez Wstawianie (Insertion Sort)

🎯 Cel lekcji:
Nauczysz się implementować algorytm sortowania przez wstawianie i zrozumiesz mechanizm przesuwania elementów w celu stworzenia luki w tablicy.

Jak działa ten algorytm?

Zanim przejdziesz do analizy kodu, przyjrzyj się poniższej symulacji. W odróżnieniu od sortowania bąbelkowego, tutaj nie zamieniamy sąsiadów miejscami raz za razem.

Gdy wybieramy element (nasz Klucz), w tablicy powstaje wolne miejsce. Inne liczby "wskakują" w tę lukę jedna po drugiej, dopóki nie znajdziemy idealnego miejsca dla naszego klucza. Zobacz, jak ta luka wędruje między kafelkami:

🎮 Symulator "Wędrującej Luki"

Wylosuj karty, aby zacząć.

💻 Mechanizm w kodzie

Zauważ, że instrukcja a[j + 1] = a[j] to dosłownie przesunięcie sąsiada w prawo, co powoduje, że "puste miejsce" przesuwa się na indeks j.

int key = a[i];  // Wyjmij element (pojawia się luka na i)
int j = i - 1;

while(j >= 0 && a[j] > key) {
    a[j + 1] = a[j]; // Sąsiad zajmuje lukę, luka przesuwa się na j
    j--;
}
a[j + 1] = key;    // Wstawiamy klucz w ostateczną lukę

⚖️ Kiedy używać Wstawiania? (Złożoność)

Sortowanie przez wstawianie ma dwie twarze. Wszystko zależy od tego, w jakim stanie jest Twoja tablica na starcie:

✅ Przypadek optymistyczny
Tablica jest już posortowana. Algorytm przejdzie przez nią tylko raz i nic nie przesunie. Działa wtedy błyskawicznie: O(n).
❌ Przypadek pesymistyczny
Tablica posortowana odwrotnie. Każdy element musi "przelecieć" na sam początek. To boli i zajmuje czas: O(n²).
Złota zasada: Jeśli dopisujesz tylko jedną nową liczbę do już posortowanej listy, Insertion Sort jest jednym z najszybszych wyborów!

⚠️ Pułapka: Najczęstszy błąd w pętli while

Przy pisaniu tego algorytmu z pamięci, najłatwiej wyłożyć się na warunku pętli:

while(j >= 0 && a[j] > key) { ... }

Dlaczego kolejność ma znaczenie? Jeśli najpierw sprawdzisz a[j] > key, a j spadnie do -1, program spróbuje odczytać a[-1]. To spowoduje błąd (wyjście poza pamięć). Zawsze najpierw sprawdzaj, czy j >= 0!

Sortowanie przez Wybór (Selection Sort)

🎯 Cel lekcji:
Poznasz kolejną metodę układania elementów w kolejności rosnącej. Zrozumiesz, jak działa algorytm, który w każdym kroku "poluje" na najmniejszą liczbę i wstawia ją na początek.

🤔 Jak działa sortowanie przez wybór? (Analogia)

Wyobraź sobie, że masz na stole nieuporządkowane karty:

  • Przechodzisz wzrokiem po wszystkich kartach i szukasz najmniejszej ze wszystkich.
  • Gdy ją znajdziesz, zamieniasz ją miejscami z pierwszą kartą na stole. Pierwsza karta jest już bezpieczna i uporządkowana!
  • Teraz szukasz najmniejszej karty spośród pozostałych (od drugiego miejsca do końca) i zamieniasz ją z drugą kartą.
  • Powtarzasz ten proces, aż wszystkie karty będą ułożone.

💻 Kod w C++

#include <iostream>
using namespace std;

int main() {
    int tab[] = {64, 25, 12, 22, 11};
    int n = 5;

    // Główna pętla przechodzi przez kolejne pozycje
    for (int i = 0; i < n - 1; i++) {
        int min_index = i; // Zakładamy, że najmniejszy jest na pozycji i

        // Szukamy mniejszego elementu w reszcie tablicy
        for (int j = i + 1; j < n; j++) {
            if (tab[j] < tab[min_index]) {
                min_index = j; // Zapamiętujemy nową najmniejszą pozycję
            }
        }

        // Zamiana miejscami (swap)
        int temp = tab[min_index];
        tab[min_index] = tab[i];
        tab[i] = temp;
    }

    // Wypisanie posortowanej tablicy
    for (int i = 0; i < n; i++) {
        cout << tab[i] << " ";
    }
    return 0;
}

Sortowanie przez scalanie (Merge Sort)

🎯 Cel lekcji:
Poznasz jeden z najszybszych algorytmów sortowania. Dowiesz się, jak rekurencyjnie dzielić problem na mniejsze części i jak efektywnie scalać posortowane podtablice w czasie O(n log n).

1. Strategia "Dziel i Zwyciężaj"

Merge Sort nie próbuje sortować wszystkiego naraz. Działa w trzech fazach:

  • Dziel: Rozbijaj tablicę na połowy, aż otrzymasz pojedyncze elementy.
  • Zwyciężaj: Każdy pojedynczy element uznaj za posortowany.
  • Scalaj: Łącz mniejsze posortowane grupy w większe, pilnując kolejności.

        mergeSort(tab, s + 1, prawy);
        merge(tab, lewy, s, prawy);

}

Sortowanie Szybkie (QuickSort)

🎯 Cel lekcji:
Poznasz jeden z najszybszych algorytmów sortowania. Zrozumiesz ideę strategii "dziel i rządź" oraz zobaczysz w akcji słynny "mur" (wskaźnik granicy), który oddziela elementy mniejsze od większych względem pivota.

🤔 Jak działa podział (Partition) i nasz "mur"?

Wyobraź sobie, że porządkujesz liczby względem wybranego elementu (pivota, zaznaczonego na czerwono):

  • Ustawiamy ruchomy mur (wskaźnik graniciący), który pokazuje, dokąd sięgają liczby mniejsze lub równe pivotowi.
  • Przechodzimy po tablicy kolejnymi elementami. Gdy trafimy na liczbę mniejszą od pivota:
    1. Przesuwamy mur w prawo o jeden krok.
    2. Zamieniamy miejscami element za murkiem z napotkaną mniejszą liczbą.
  • Dzięki temu mniejsze elementy automatycznie lądują po lewej stronie muru!

💻 Kod w C++ (Wersja rekurencyjna)

#include <iostream>
using namespace std;

int partition(int tab[], int low, int high) {
    int pivot = tab[high]; // Ostatni element jako pivot
    int i = (low - 1);     // Nasz "mur" zaczyna się przed tablicą

    for (int j = low; j <= high - 1; j++) {
        if (tab[j] <= pivot) {
            i++; // Przesuwamy mur w prawo
            // Zamiana elementów
            int temp = tab[i];
            tab[i] = tab[j];
            tab[j] = temp;
        }
    }
    // Wstawienie pivota na właściwe miejsce tuż za murem
    int temp = tab[i + 1];
    tab[i + 1] = tab[high];
    tab[high] = temp;
    return (i + 1);
}

void quickSort(int tab[], int low, int high) {
    if (low < high) {
        int pi = partition(tab, low, high);
        quickSort(tab, low, pi - 1);  // Lewa strona
        quickSort(tab, pi + 1, high); // Prawa strona
    }
}

int main() {
    int tab[] = {10, 7, 8, 9, 1, 5};
    int n = 6;
    quickSort(tab, 0, n - 1);
    return 0;
}

🎯 Cel lekcji:

🔍 Zasada "Dziel i Zwyciężaj"

Wyobraź sobie, że szukasz słowa w papierowym słowniku. Nie kartkujesz go strona po stronie od początku. Otwierasz go na środku i sprawdzasz: czy moje słowo jest dalej, czy wcześniej? Tym samym jednym ruchem odrzucasz połowę książki. To właśnie robi wyszukiwanie binarne.

🎮 Symulator: Strategia Połowienia

💻 Kod C++ (Wersja iteracyjna)

Kluczem jest zmienna srodek, która jest wyliczana w każdej iteracji pętli jako średnia z lewy i prawy.

int binarySearch(int tab[], int n, int szukana) {
    int lewy = 0, prawy = n - 1;
    
    while (lewy <= prawy) {
        int srodek = lewy + (prawy - lewy) / 2;
        
        if (tab[srodek] == szukana) return srodek; // Znaleziono!
        
        if (tab[srodek] < szukana) 
            lewy = srodek + 1; // Szukamy w prawej połowie
        else 
            prawy = srodek - 1; // Szukamy w lewej połowie
    }
    return -1; // Nie ma w tablicy
}

Największy Wspólny Dzielnik (Algorytm Euklidesa) i Najmniejsza Wspólna Wielokrotność

🎯 Cel lekcji:
Nauczysz się wyznaczać największą liczbę, która dzieli bez reszty dwie inne liczby. Poznasz algorytm Euklidesa w wersji z odejmowaniem oraz optymalnej wersji z resztą z dzielenia (modulo).

📚 Na czym polega Algorytm Euklidesa?

Euklides wieki temu zauważył, że jeśli od większej liczby odejmiemy mniejszą, to ich wspólny dzielnik się nie zmieni. Powtarzając to, w końcu dojdziemy do momentu, w którym liczby będą równe – ta liczba to nasz NWD.

Przykład: NWD(24, 18)
1. 24 - 18 = 6. Mamy teraz liczby (6, 18).
2. 18 - 6 = 12. Mamy teraz (6, 12).
3. 12 - 6 = 6. Mamy teraz (6, 6).
4. Liczby są równe. NWD = 6.

🚀 Wersja optymalna (z modulo)

Odejmowanie jest wolne (np. dla NWD(1000000, 2)). Dużo szybciej jest użyć reszty z dzielenia (%). W C++ na maturze piszemy to zazwyczaj tak:

int a, b;
cin >> a >> b;

while (b != 0) {
    int temp = b;
    b = a % b;
    a = temp;
}

cout << "NWD to: " << a;
💡 Jak to działa?
W każdym kroku pętli mniejsza liczba (b) staje się resztą z dzielenia większej przez mniejszą, a większa (a) przyjmuje poprzednią wartość b. Pętla kończy się, gdy b wyniesie 0. Wtedy wynik znajduje się w zmiennej a.

💻 Kod: Implementacja w C++

Zauważ, że używamy tablicy typu bool. Wartość true oznacza u nas "liczba jest pierwsza".

void Sito(bool pierwsze[], int n) {
    // 1. Zakładamy na początku, że wszystkie są pierwsze
    for(int i = 2; i <= n; i++) pierwsze[i] = true;

    for(int i = 2; i * i <= n; i++) {       // 2. Sprawdzamy do pierwiastka z N
        if(pierwsze[i]) {                   // 3. Jeśli i jest pierwsza...
            for(int j = i * i; j <= n; j += i) {
                pierwsze[j] = false;        // 4. ...to wykreśl jej wielokrotności
            }
        }
    }
}

To genialna optymalizacja. Jeśli liczba ma dzielnik, to przynajmniej jeden z nich musi być mniejszy lub równy pierwiastkowi z tej liczby. Dzięki temu algorytm kończy pracę znacznie szybciej!

💻 Algorytm "Dziel przez najmniejszą"

Zasada jest prosta: próbujemy dzielić liczbę przez kolejne liczby pierwsze (2, 3, 5...), dopóki się da. Jeśli nie da się już dzielić przez 2, przechodzimy do 3, i tak dalej.

void Rozklad(int n) {
    int k = 2; // Zaczynamy od najmniejszej liczby pierwszej
    while (n > 1) {
        while (n % k == 0) { // Dopóki n dzieli się przez k
            cout << k << " "; // Wypisz czynnik
            n /= k;           // Zmniejsz n
        }
        k++; // Sprawdź kolejną liczbę
    }
}
🚀 Optymalizacja:

Liczby doskonałe – Suma dzielników

🎯 Cel lekcji:

📚 Co to jest liczba doskonała?

Liczba doskonała to taka liczba naturalna, która jest sumą wszystkich swoich dzielników właściwych (czyli wszystkich dzielników mniejszych od niej samej).

Przykład: Liczba 6

2. Sumujemy je: 1 + 2 + 3 = 6.
3. Wynik jest równy liczbie startowej, więc 6 jest liczbą doskonałą!

Kolejną liczbą doskonałą jest 28 (1 + 2 + 4 + 7 + 14 = 28).

🛠️ Jak to zapisać w C++?

int n, suma = 0;

    }
}

if (suma == n) {
    cout << "Liczba " << n << " jest doskonala!";
} else {
    cout << "To nie jest liczba doskonala.";
}

Systemy liczbowe: Binarny, Ósemkowy i Szesnastkowy

🎯 Cel lekcji:
Zrozumiesz zasady działania systemów o podstawie innej niż 10. Nauczysz się algorytmów konwersji w obie strony (mnożenie pozycyjne i dzielenie z resztą), szybkiego grupowania bitów dla systemów 8 i 16, a na koniec stworzysz uniwersalny "kombajn" do zamiany dowolnego systemu na inny.

🔢 Dlaczego inne systemy?

Na co dzień używamy systemu dziesiętnego (DEC), bo mamy 10 palców. Komputery mają "dwa palce" – płynie prąd albo nie – więc używają systemu binarnego (BIN, podstawa 2). Z kolei systemy ósemkowy (OCT, podstawa 8) i szesnastkowy (HEX, podstawa 16) powstały po to, aby zapisywać długie ciągi jedynek i zer w dużo krótszej, czytelniejszej dla człowieka formie.

BIN (2)
Cyfry: 0, 1
OCT (8)
Cyfry: 0-7
HEX (16)
Cyfry: 0-9, A-F (A=10, B=11...)

➡️ 1. Zamiana z DOWOLNEGO systemu na Dziesiętny (X → 10)

Aby zamienić np. liczbę binarną czy szesnastkową na dziesiętną, korzystamy z wartości pozycyjnych. Każdą cyfrę mnożymy przez podstawę systemu podniesioną do potęgi odpowiadającej pozycji tej cyfry (licząc od zera, od prawej strony).

🎮 Symulator: Rozkład Pozycyjny (X → 10)

💻 Kod C++ (Dowolny → 10)

W kodzie zapisujemy liczbę jako tekst (string), bo w systemie HEX pojawiają się litery. Idziemy od prawej do lewej, mnożąc przez kolejne potęgi podstawy.

int toDecimal(string num, int base) {
    int result = 0;
    int power = 1; // base^0

    // Idziemy od ostatniego znaku (prawej strony)
    for (int i = num.length() - 1; i >= 0; i--) {
        int digit;
        if (num[i] >= '0' && num[i] <= '9') {
            digit = num[i] - '0'; // Zamiana znaku na cyfrę
        } else {
            digit = num[i] - 'A' + 10; // Zamiana litery A-F na 10-15
        }
        
        result += digit * power;
        power *= base; // Zwiększamy potęgę: 1, base, base^2...
    }
    return result;
}

⬅️ 2. Zamiana z Dziesiętnego na DOWOLNY system (10 → X)

Aby wygenerować liczbę w nowym systemie, bierzemy naszą liczbę dziesiętną i dzielimy ją z resztą przez docelową podstawę (np. 2). Zapisujemy reszty, a wynik dzielenia dzielimy dalej, aż dotrzemy do zera. Odczytane od dołu reszty tworzą nowy zapis!

💻 Kod C++ (10 → Dowolny)

Algorytm wyciąga reszty (modulo), dodaje je do stringa, a na sam koniec odwraca całe słowo, bo reszty uzyskujemy od końca (od cyfr najmniej znaczących).

#include <algorithm> // Dla funkcji reverse

string fromDecimal(int num, int base) {
    if (num == 0) return "0";
    string result = "";

    while (num > 0) {
        int rem = num % base; // Obliczamy resztę
        
        if (rem < 10) {
            result += to_string(rem); // Cyfry 0-9
        } else {
            result += (char)('A' + (rem - 10)); // Litery A-F dla systemu 16
        }
        num /= base; // Dzielimy całkowitoliczbowo
    }
    
    // Reszty czytamy od końca, więc odwracamy tekst!
    reverse(result.begin(), result.end());
    return result;
}

🚀 3. Szybka konwersja (Grupowanie 2 ↔ 8 ↔ 16)

Matematyka skrywa piękny sekret. Ponieważ 8 to dokładne 2³, a 16 to 2⁴, możemy przeskakiwać między systemem binarnym a ósemkowym/szesnastkowym bez zamiany na system dziesiętny!

Binarny na Ósemkowy (Paczki po 3 bit)
Dzielimy kod binarny od prawej na grupy 3-bitowe. Każda grupa to dokładnie jedna cyfra w systemie 8.
Przykład: 10 110 001 (BIN)
Rozkodowanie: (010)=2, (110)=6, (001)=1 ➔ 261 (OCT)
Binarny na Szesnastkowy (Paczki po 4 bit)
Dzielimy kod od prawej na grupy 4-bitowe (tzw. nibble). Każda grupa to jedna cyfra w systemie 16.
Przykład: 1011 0001 (BIN)
Rozkodowanie: (1011)=11(czyli B), (0001)=1 ➔ B1 (HEX)

⚙️ 4. Ultimate Base Converter (Kombajn Konwersji)

Skoro potrafimy zamienić dowolny system na dziesiętny (Punkt 1), oraz dziesiętny na dowolny system (Punkt 2), wystarczy połączyć te dwie funkcje, by uzyskać uniwersalny tłumacz systemów liczbowych!

string convertBase(string number, int baseFrom, int baseTo) {
    // 1. Zamieniamy wejście na wspólny mianownik (system dziesiętny)
    int decimalValue = toDecimal(number, baseFrom);
    
    // 2. Tłumaczymy system dziesiętny na docelowy
    return fromDecimal(decimalValue, baseTo);
}

Schemat Hornera (Czyli jak sprytnie liczyć wielomiany)

🎯 Cel lekcji:
Poznasz genialny w swojej prostocie algorytm matematyka Williama Hornera. Zrozumiesz, jak zamieniać potęgowanie wielomianów na szybkie mnożenia i dodawania oraz jak schemat ten pomaga m.in. w zamianie systemów liczbowych.

🤔 O co w tym chodzi? (Matematyczny trik)

Wyobraź sobie, że musisz obliczyć wartość wielomianu dla danego $x$, np.:

$W(x) = 2x^3 + 3x^2 + x + 5$

Gdyby robić to "na pałę", musiałbyś liczyć osobno $x^3$, osobno $x^2$, mnożyć przez współczynniki... co prowadzi do wielu operacji i błędów.

Pan Horner zauważył, że ten sam wielomian można zapisać w postaci "gniazdowej" (wyciągając $x$ przed nawias krok po kroku):

$W(x) = ((2x + 3)x + 1)x + 5$

Dzięki temu wykonujesz tylko kilka prostych operacji: mnożysz dotychczasowy wynik przez $x$ i dodajesz kolejny współczynnik!

💻 Kod w C++ (Obliczanie wartości wielomianu)

#include <iostream>
using namespace std;

// tablica współczynników: a_n, a_{n-1}, ..., a_0
// n - stopień wielomianu, x - argument
double horner(int wsp[], int n, double x) {
    double wynik = wsp[0]; // Zaczynamy od najwyższego współczynnika

    for (int i = 1; i <= n; i++) {
        wynik = wynik * x + wsp[i];
    }

    return wynik;
}

int main() {
    // Wielomian: 2x^3 + 3x^2 + 1x + 5
    int wspolczynniki[] = {2, 3, 1, 5}; 
    int stopień = 3;
    double x = 2.0;

    double wynik = horner(wspolczynniki, stopień, x);
    cout << "Wartosc wielomianu dla x = " << x << " wynosi: " << wynik;
    return 0;

Rekurencja - Silnia, Ciąg Fibonacciego i Szybkie Potęgowanie

🎯 Cel lekcji:
Opanujesz myślenie rekurencyjne na trzech klasycznych przykładach: silni, ciągu Fibonacciego oraz szybkiego potęgowania. Dowiesz się, jak unikać błędów przepełnienia stosu.

1. Fundamenty Rekurencji

Rekurencja to technika, w której funkcja rozwiązuje duży problem, dzieląc go na mniejsze podproblemy tego samego typu.

Aby funkcja nie działała w nieskończoność, musi posiadać przypadek bazowy (warunek stopu). Każde kolejne wywołanie musi przybliżać nas do tego warunku.

2. Przykład 1: Silnia (Klasyka)

Silnia z n (zapisywana jako n!) to iloczyn wszystkich liczb od 1 do n.
Definicja rekurencyjna: n! = n * (n-1)!, przy czym 0! = 1.

long long silnia(int n) {
    if (n == 0) return 1; // Warunek stopu
    return n * silnia(n - 1); // Krok: n * silnia mniejszej liczby
}

3. Przykład 2: Ciąg Fibonacciego (Pułapka wydajności)

Każdy wyraz jest sumą dwóch poprzednich: 0, 1, 1, 2, 3, 5, 8, 13...
Definicja: F(n) = F(n-1) + F(n-2).

int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}

⚠️ Uwaga: Ta wersja jest bardzo wolna dla dużych n, bo wielokrotnie liczy to samo!

4. Przykład 3: Szybkie Potęgowanie (Must-know)

To kluczowy algorytm na maturę rozszerzoną. Zamiast mnożyć "na piechotę", wykorzystujemy parzystość wykładnika.

Implementacja C++ (Rekurencyjna z Modulo)

Wersja bezpieczna, która nie "wybuchnie" przy dużych liczbach dzięki zastosowaniu modulo.

long long szybka_potega(long long a, long long n, long long m) {
    if (n == 0) return 1;
    if (n % 2 == 0) {
        long long x = szybka_potega(a, n / 2, m);
        return (x * x) % m;
    } else {
        return (a * szybka_potega(a, n - 1, m)) % m;
    }
}

Sumy prefiksowe (Prefix Sums)

🎯 Cel lekcji:
Nauczysz się techniki sum prefiksowych, która pozwala błyskawicznie (w czasie stałym) obliczać sumę elementów na dowolnym fragmencie tablicy. To jeden z najważniejszych algorytmów optymalizacyjnych na konkursach informatycznych!

🐢 Problem powolnych zapytań

Wyobraź sobie tablicę z milionem liczb i aplikację, która milion razy pyta: "Jaka jest suma elementów od indeksu L do indeksu R?". Pętla idąca za każdym razem od L do R (podejście naiwne) potrwa wieki, ponieważ złożoność takiego programu to aż O(N * Q) (gdzie N to wielkość tablicy, a Q to liczba zapytań).

🚀 Rozwiązanie: "Stan konta" (O(1) na zapytanie)

Zamiast liczyć w kółko to samo, możemy raz przejść przez tablicę i stworzyć dodatkową tablicę sum prefiksowych (Pref). Pod indeksem i trzyma ona sumę wszystkich elementów od początku tablicy (od 0) aż do i. Działa to jak bieżące saldo na koncie po każdej transakcji.

Suma(L, R) = Pref[R] - Pref[L - 1]
(Jeśli L = 0, to suma wynosi po prostu Pref[R])

💻 Kod C++ (Budowa i Zapytanie)

Oto optymalny sposób implementacji. Zwróć uwagę na obsługę przypadku, gdy L == 0, aby nie odwołać się do indeksu -1.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> A = {2, 4, 1, 5, 3, 8, 1};
    int n = A.size();
    
    // 1. Budowa tablicy sum prefiksowych
    vector<int> Pref(n);
    Pref[0] = A[0];
    for (int i = 1; i < n; i++) {
        Pref[i] = Pref[i - 1] + A[i];
    }
    
    // 2. Szybkie zapytanie o przedział [L, R]
    int L = 2, R = 5;
    int suma;
    
    if (L == 0) {
        suma = Pref[R];
    } else {
        suma = Pref[R] - Pref[L - 1];
    }
    
    cout << "Suma to: " << suma << endl;
    return 0;
}

bool czyPalindrom(string s) {

1. Co to jest Anagram?

Dwa słowa są anagramami, jeśli składają się z tych samych liter, w tej samej liczbie, ale w innej kolejności (np. EKRAN i NERKA, KARTON i NARKOT).

Sposób naiwny: Posortuj oba słowa i sprawdź, czy są identyczne. (Wolniejsze: $O(N \log N)$)
Sposób optymalny: Policz litery w obu słowach. Jeśli licznik każdej litery się zgadza – to anagram. (Szybsze: $O(N)$)

2. Metoda Kubełkowa (Histogram)

Wyobraź sobie 256 pudełek (tyle jest znaków w rozszerzonym kodzie ASCII). Przechodząc przez słowo, wrzucasz "kulkę" do pudełka odpowiadającego danej literze.

bool czyAnagram(string s1, string s2) {
    if (s1.length() != s2.length()) return false;

    int liczniki[256] = {0}; // Zerujemy tablicę

    for (int i = 0; i < s1.length(); i++) {
        liczniki[(int)s1[i]]++; // Dodaj literę z 1. słowa
        liczniki[(int)s2[i]]--; // Odejmij literę z 2. słowa
    }

    for (int i = 0; i < 256; i++) {
        if (liczniki[i] != 0) return false;
    }
    return true;
}

🎯 Cel lekcji:
Opanujesz trzy kluczowe typy szyfrów klasycznych wymagane na maturze z informatyki. Zrozumiesz ich działanie, zobaczysz pełne implementacje w C++ oraz przetestujesz je na interaktywnych symulatorach.

1. Szyfr Cezara (Szyfr podstawieniowy)

Każda litera tekstu jawnego zostaje przesunięta o stałą liczbę pozycji ($k$) w alfabecie. Gdy "dobijemy" do końca alfabetu (litera Z), przechodzimy z powrotem na początek (używamy operacji modulo).

// Szyfr Cezara w C++
string szyfrujCezara(string tekst, int klucz) {
    string wynik = "";
    for (int i = 0; i < tekst.length(); i++) {
        char c = tekst[i];
        if (c >= 'A' && c <= 'Z') {
            wynik += (c - 'A' + klucz) % 26 + 'A';
        } else {
            wynik += c; // Zachowaj spacje/inne znaki
        }
    }
    return wynik;
}

}

Metody numeryczne: Metoda bisekcji

🎯 Cel lekcji:
Nauczysz się znajdować przybliżone miejsce zerowe funkcji w zadanym przedziale. Zrozumiesz, jak "inteligentne zgadywanie" pozwala komputerowi rozwiązywać równania, których nie da się przekształcić wzorami.

1. Warunek konieczny

Aby metoda bisekcji zadziałała w przedziale [a, b], funkcja musi być ciągła, a jej wartości na końcach przedziału muszą mieć przeciwne znaki. Oznacza to, że:

f(a) * f(b) < 0

2. Algorytm krok po kroku

  1. Wyznacz środek przedziału: s = (a + b) / 2.
  2. Sprawdź wartość funkcji w środku: f(s).
  3. Jeśli f(s) ma ten sam znak co f(a), to miejsce zerowe jest w prawej połowie – nowe a = s.
  4. W przeciwnym razie miejsce zerowe jest w lewej połowie – nowe b = s.
  5. Powtarzaj, aż przedział będzie mniejszy niż zadana dokładność (epsilon).

3. Implementacja w C++

double bisekcja(double a, double b, double epsilon) {
    double s;
    while ((b - a) > epsilon) {
        s = (a + b) / 2.0;
        if (f(a) * f(s) < 0) 
            b = s; // Lewa połowa
        else 
            a = s; // Prawa połowa
    }
    return (a + b) / 2.0;
}

Metody numeryczne: Pola pod wykresem

🎯 Cel lekcji:
Nauczysz się obliczać przybliżone pole powierzchni pod wykresem funkcji (całkowanie numeryczne) za pomocą dwóch popularnych metod: prostokątów i trapezów.

1. Idea całkowania numerycznego

Pole pod wykresem funkcji f(x) w przedziale [a, b] dzielimy na n mniejszych odcinków (pasków). Im więcej takich odcinków wybierzemy, tym dokładniejszy wynik otrzymamy.

2. Metoda Prostokątów

Każdy odcinek traktujemy jak prostokąt. Jego szerokość to dx = (b-a)/n, a wysokość to wartość funkcji w środku tego odcinka.

double poleProstokatow(double a, double b, int n) {
    double dx = (b - a) / n;
    double suma = 0;
    for (int i = 0; i < n; i++) {
        double x_srodkowe = a + i * dx + dx / 2.0;
        suma += f(x_srodkowe);
    }
    return suma * dx;
}

3. Metoda Trapezów

Zamiast prostokątów, używamy trapezów, których górna krawędź łączy wartości funkcji na końcach przedziału. Pole jednego trapezu liczymy ze wzoru: ((f(x1) + f(x2)) / 2) * dx.

double poleTrapezow(double a, double b, int n) {
    double dx = (b - a) / n;
    double suma = 0;
    for (int i = 0; i < n; i++) {
        suma += (f(a + i * dx) + f(a + (i + 1) * dx)) / 2.0;
    }
    return suma * dx;
}

Odwrotna Notacja Polska (ONP / RPN)

🎯 Cel lekcji:
Opanujesz pojęcie Odwrotnej Notacji Polskiej (ONP). Nauczysz się przekształcać zwykłe wyrażenia algebraiczne (notacja infiksowa) na ONP oraz obliczać ich wartość za pomocą stosu, co jest kluczowym elementem matury z informatyki.

🤔 O co w ogóle chodzi?

Gdy piszesz 2 + 3 * 4, człowiek wie, co zrobić najpierw. Komputer gubi się w kolejności działań i nawiasach. W Odwrotnej Notacji Polskiej (ONP) operator stoi ZA swoimi argumentami, dzięki czemu nie potrzebujemy nawiasów, a kolejność wykonywania jest jednoznaczna od lewa do prawa!

  • Zapis tradycyjny (infiksowy): (2 + 3) * 4
  • Zapis ONP (postfiksowy): 2 3 + 4 *

Część 1: Zamiana z Notacji Infiksowej na ONP

Aby przekształcić zwykły napis na ONP, stosujemy algorytm stacji rozrządowej z użyciem stosu na operatory oraz uwzględnieniem priorytetów działań (`*` i `/` mają wyższy priorytet niż `+` i `-`).

// Implementacja w C++: Zamiana wyrażenia infiksowego na ONP
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int priorytet(char op) {
    if (op == '+' || op == '-') return 1;
    if (op == '*' || op == '/') return 2;
    return 0;
}

string infiksNaONP(string infiks) {
    string onp = "";
    stack<char> stos;
    
    for (int i = 0; i < infiks.length(); i++) {
        char c = infiks[i];
        
        // Jeśli to operand (litera/cyfra), dodaj do wyniku
        if (isalnum(c)) {
            onp += c;
            onp += " ";
        } 
        // Jeśli lewy nawias, wrzuć na stos
        else if (c == '(') {
            stos.push(c);
        } 
        // Jeśli prawy nawias, zdejmuj ze stosu do napotkania '('
        else if (c == ')') {
            while (!stos.empty() && stos.top() != '(') {
                onp += stos.top();
                onp += " ";
                stos.pop();
            }
            if (!stos.empty()) stos.pop(); // usuń '(' ze stosu
        } 
        // Jeśli operator
        else if (c == '+' || c == '-' || c == '*' || c == '/') {
            while (!stos.empty() && priorytet(stos.top()) >= priorytet(c)) {
                onp += stos.top();
                onp += " ";
                stos.pop();
            }
            stos.push(c);
        }
    }
    // Opróżnij resztę stosu
    while (!stos.empty()) {
        onp += stos.top();
        onp += " ";
        stos.pop();
    }
    return onp;
}

Część 2: Obliczanie wartości wyrażenia ONP (Najważniejsze na maturze!)

Czytamy wyrażenie w ONP od lewa do prawa. Liczby wrzucamy na stos. Napotkany operator pobiera ze stosu dwa ostatnie elementy, wykonuje na nich obliczenia i wrzuca wynik z powrotem na stos.

// Implementacja w C++: Obliczanie wartości wyrażenia w ONP
#include <iostream>
#include <stack>
#include <string>
#include <sstream>
using namespace std;

double obliczONP(string wyraz) {
    stack<double> stos;
    stringstream ss(wyraz);
    string token;

    while (ss >> token) {
        if (token != "+" && token != "-" && token != "*" && token != "/") {
            stos.push(stod(token)); // Jeśli to liczba, wrzuć na stos
        } else {
            double b = stos.top(); stos.pop(); // Drugi argument
            double a = stos.top(); stos.pop(); // Pierwszy argument
            
            if (token == "+") stos.push(a + b);
            else if (token == "-") stos.push(a - b);
            else if (token == "*") stos.push(a * b);
            else if (token == "/") stos.push(a / b);
        }
    }
    return stos.top(); // Ostateczny wynik na szczycie stosu
}

Kolejka (Queue) – Mechanizm FIFO

🎯 Cel lekcji:

1. Zasada działania: FIFO

Skrót FIFO oznacza First In, First Out (Pierwszy wszedł, pierwszy wyszedł). Elementy są dodawane na koniec kolejki (tył), a usuwane z jej początku (przód).

2. Podstawowe operacje

  • push(x) – dodaje element x na koniec kolejki (enqueue).
  • pop() – usuwa element znajdujący się na samym początku (dequeue).
  • front() – zwraca wartość elementu z początku (pierwszego w kolejce).
  • back() – zwraca wartość elementu z samego końca (ostatniego dodanego).
  • empty() – sprawdza, czy kolejka jest pusta.

Drzewa Binarne i BST

💡 Hierarchia zamiast kolejki:
W przeciwieństwie do list, drzewa są strukturami nieliniowymi. Pozwalają one na błyskawiczne wyszukiwanie danych dzięki porządkowaniu elementów w relacji rodzic-dziecko.

1. Anatomia Drzewa Binarnego

W drzewie binarnym każdy węzeł (Node) posiada co najwyżej dwoje dzieci. Kluczowe pojęcia to:

  • Korzeń (Root): Pierwszy węzeł, "głowa" całego drzewa.
  • Liście (Leaves): Węzły na samym dole, które nie mają potomków.
  • Wysokość: Liczba poziomów od korzenia do najdalszego liścia.

2. Binary Search Tree (BST) – Zasada Lewo/Prawo

BST to drzewo, które automatycznie sortuje dane podczas ich wstawiania:

JEŚLI nowa_wartość < rodzic -> IDŹ NA LEWO
JEŚLI nowa_wartość > rodzic -> IDŹ NA PRAWO

Dzięki tej prostej zasadzie, szukając liczby, w każdym kroku odrzucamy połowę drzewa. To sprawia, że szukanie ma złożoność O(log n).

3. Implementacja w C++ (Standard 06)

W C++ 06 węzeł drzewa definiujemy jako strukturę z dwoma wskaźnikami typu Node*.

struct Node {
    int klucz;
    Node *left, *right;

    // Konstruktor (zgodny z C++ 06)
    Node(int val) {
        klucz = val;
        left = right = NULL;
    }
};

// Funkcja wstawiająca - rekurencyjna
Node* insert(Node* root, int val) {
    if (root == NULL) return new Node(val);

    if (val < root->klucz)
        root->left = insert(root->left, val);
    else
        root->right = insert(root->right, val);

    return root;
}

Przeszukiwanie grafów: BFS (Breadth-First Search)

🌊 Przeszukiwanie Wszerz:
Algorytm BFS odwiedza najpierw wszystkich bezpośrednich sąsiadów wierzchołka startowego, a dopiero potem przechodzi do sąsiadów kolejnego poziomu. Przypomina to falę rozchodzącą się po wodzie.

1. Jak działa BFS?

Algorytm wykorzystuje dwie kluczowe koncepcje:

  • Kolejka (FIFO): Przechowuje wierzchołki oczekujące na przetworzenie. Pierwszy dodany wierzchołek jest przetwarzany jako pierwszy.
  • Tablica odwiedzonych (visited): Zapobiega wpadnięciu w nieskończoną pętlę i ponownemu odwiedzaniu tych samych węzłów.
Złożoność obliczeniowa:
• Czasowa: O(V + E), gdzie V to liczba wierzchołków, a E to liczba krawędzi.
• Pamięciowa: O(V) na potrzebę kolejki i tablicy odwiedzin.

2. Implementacja w C++ (Standard 06)

Do implementacji wykorzystujemy standardową kolejkę std::queue oraz tablicę wartości logicznych bool.

#include <iostream>
#include <vector>
#include <queue>

using namespace std;

void bfs(int startNode, const vector<vector<int> >& adj, int V) {
    vector<bool> visited(V, false);
    queue<int> q;

    visited[startNode] = true;
    q.push(startNode);

    while (!q.empty()) {
        int curr = q.front();
        q.pop();
        cout << "Odwiedzono: " << curr << endl;

        // Przeglądanie wszystkich sąsiadów obecnego wierzchołka
        for (size_t i = 0; i < adj[curr].size(); ++i) {
            int neighbor = adj[curr][i];
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}

Przeszukiwanie Grafów: DFS (Depth-First Search)

🕳️ Algorytm drążący (w głąb):
DFS wybiera jednego sąsiada i idzie jego ścieżką do samego końca. Gdy dotrze do ślepego zaułka (brak nieodwiedzonych sąsiadów), wycofuje się (tzw. backtracking) do ostatniego wierzchołka, który miał jeszcze inne opcje.

1. Jak działa DFS?

Algorytm opiera swoje działanie na dwóch mechanizmach:

  • Stos LIFO (Stack): Przechowuje aktualną ścieżkę (można użyć jawnego stosu lub stosu wywołań funkcji rekurencyjnej).
  • Tablica odwiedzonych (Visited): Informuje, które wierzchołki zostały już przetworzone, co zapobiega pętlom.
Kroki algorytmu (wersja stosowa/rekurencyjna):
  1. Oznacz aktualny wierzchołek jako odwiedzony.
  2. Dla każdego jego nieodwiedzonego sąsiada, przejdź do niego natychmiast (wejście w głąb).
  3. Jeśli wierzchołek nie ma już nieodwiedzonych sąsiadów, cofnij się do poprzednika (backtrack).

#include <iostream>
#include <vector>

using namespace std;

void dfsRecursive(int u, vector<int> adj[], vector<bool>& visited) {
    visited[u] = true;
    cout << u << " ";

    // Schodzimy w głąb do pierwszego nieodwiedzonego sąsiada
    for (size_t i = 0; i < adj[u].size(); ++i) {
        int v = adj[u][i];
        if (!visited[v]) {
            dfsRecursive(v, adj, visited);
        }
    }
}

void dfs(int startNode, vector<int> adj[], int V) {
    vector<bool> visited(V, false);
    dfsRecursive(startNode, adj, visited);
}

#include <iostream>
#include <fstream>
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

// Definicja struktury dla jednego wiersza z pliku
struct Kandydat {
    string nazwisko;
    int punkty;
};

// Funkcja porównująca (komparator) dla std::sort
bool porownaj(const Kandydat& a, const Kandydat& b) {
    if (a.punkty != b.punkty) {
        return a.punkty > b.punkty; // 1. Malejąco po punktach
    }
    return a.nazwisko < b.nazwisko;  // 2. Rosnąco (alfabetycznie) po nazwisku
}

int main() {
    ifstream plik("dane.txt");
    vector<Kandydat> lista;
    Kandydat temp;

    // Bezpieczne wczytywanie z pliku wiersz po wierszu
    while (plik >> temp.nazwisko >> temp.punkty) {
        lista.push_back(temp);
    }
    plik.close();

    // Sortowanie z użyciem komparatora
    sort(lista.begin(), lista.end(), porownaj);

    // Wyświetlenie wyników
    for (size_t i = 0; i < lista.size(); ++i) {
        cout << lista[i].nazwisko << " " << lista[i].punkty << "\n";
    }

    return 0;
